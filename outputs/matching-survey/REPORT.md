# 디자이너 맞춤 추천 조사

기준: Archive 후속 수정 커밋 e6bb710. 작업 브랜치 codex/designer-matching-survey.

최신 Figma 화면은 920:5295(성별), 920:4433(지역), 920:5341(강점), 920:4881(상담), 920:4919(불편 경험)이다. 최초 분석 시 이전 717번 시안을 확인했으나 사용자 이미지와 대조하여 최신 920번 세트로 바로잡았다. 최종 구현에는 최신 세트의 사진, 카드 구성, 문구와 배치를 사용한다.

- 질문 상단 147px, 진행 표시 64px, 24px 좌우 여백, 56px 하단 CTA를 기준으로 적용.
- 성별: Figma 원본 인물 사진 173px 원형 및 크롭, 선택 시 기존 취향 조사와 같은 외곽선/컬러 처리.
- 강점: 기존 Figma 사진 3장, 145px 높이 카드, 설명과 오버레이. 선택 시 외곽선.
- 상담: 최신 Figma 칩 목록과 최대 3개 선택 제한, 기존 취향 조사와 같은 선택 후 검정/흰색 처리.
- 불편 경험: 108×154px 카드 6개, 3열 2행, 세로 간격 22px, 회색 비선택/검정 선택, Figma 원본 SVG 6개와 설명, 디자이너 추천 받기 버튼.
- 사용자 이미지의 선택 상태는 예시이며 실제 사용자 응답을 미리 생성하지 않는다.
- 기존 ‘특별한 경험 없음’은 카드 아래 보조 선택으로 유지. 부정적 경험과 동시에 선택되지 않는다.
- 기존 지역 선택 데이터(성수/강남/홍대/상관없어요)와 추천 결과 로직을 유지. 지역 선택은 실제 선택 가능한 바텀시트로 연결하며 존재하지 않는 주소 검색 API를 표시하지 않는다.
- 기존 hairus.prototype.v1 matching 키에 응답 저장. 저장 콘텐츠·예약·취향 데이터 초기화 없음.
- 기존 로그인 후 취향 조사 컴포넌트는 별도 유지. 맞춤 추천에만 새 화면 적용.

검증: pnpm typecheck 및 build 통과. pnpm test 기존 28개 통과. Chrome 모바일 에뮬레이션 375px/430px에서 26개 검증 통과, 런타임 오류 0. 선택 제한, 다음 비활성화, 새로고침 복원, 기존 추천 결과 연결, 기존 취향 조사의 활성 색상과 일치, 경험 카드 크기 및 배치, 특별한 경험 없음의 배타 선택 확인. 실물 기기와 Safari 검수는 미실시.

변경 코드: src/components/prototype/surveys.tsx, matching-survey.tsx, matching-survey.module.css. Figma 사진/SVG는 기존 public/assets/figma/v1 리소스 재사용. 이 폴더의 verify.cjs, qa.json 및 PNG 6장이 재현 스크립트와 검수 기록이다.
