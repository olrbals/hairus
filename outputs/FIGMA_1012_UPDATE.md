## 주요 변경과 결정

- Home 구현 기준은 `920:5063`으로 변경. 내부 In Focus `920:5065` 계열의 캡션 `I920:5072;692:1624`는 16px 유지. 독립 조각 `920:3454`의 영문은 “Soft bob · Soft wave”, Home 내부는 “Soft bob · Shape”. 서로 덮어쓰지 않고 각 맥락을 보존한다.
- Saved는 `920:3594` Archive라는 최종 디자인이 있으므로 더 이상 전체 신규 설계 대상으로 취급하지 않는다. 빈 상태 등 실제로 없는 상태만 보완한다.
- 결과 `920:5488`은 Hair Details(기장·앞머리·텍스처·커트·컬러), Other Features(얼굴형·목 길이·피부톤)의 8개 필드를 보여준다. 기존 Q05의 표시 필드 질문은 해결한다. 정확도를 주장하지 않고 Mock 표기·unknown·사용자 편집 분리 원칙을 유지한다.
- 편집 `920:5708 / 5738`은 기존 초안 기반 임의 설계 대상에서 제외. 다른 필드는 동일 시트 시스템으로 후속 설계한다.
- 최신 `intro 920:5612`는 Welcome으로 매핑한다. 이름 입력이 추가되며 민서는 예시이므로 고정 사용자 이름으로 저장하지 않는다.
- Splash의 별도 최종 시안은 확인하지 못했다. 온보딩 3개는 두 최종 섹션에 없으며 외부 후보가 존재한다. 사용자가 **시연용 디자인 시스템으로 새로 구성**하도록 명시적으로 선택했다. 외부 후보를 최종안으로 채택하지 않는다.
- 배너 중복과 Article01 중복은 삭제하지 않는다. 이번 단계에서 구현하지 않으며 후속 상세 속성 비교에서 실제 차이가 있을 때만 질문한다.
- 배너 주석의 “다시는 떠오르지 않음”은 기존 사용자 확정(닫기=세션, 오늘 숨김=서울 날짜)과 충돌하므로 기존 확정 정책을 유지한다.
- 헤어샵의 “1,004명의 디자이너”, 디자이너 필터 지역의 숏/미디엄/롱, Article02~04 반복 본문과 팝업 날짜 불일치는 여전히 후속 교정 대상이다.

## 중복 정밀 확인

배너 ISSUE 920:3953/3975와 POPUP 920:3964/3986은 하위 크기·상대좌표·fills·effects·타이포그래피 비교 결과 동일하다. 페이지 배치 위치와 노드 ID는 제외했다. Article01 920:4077/4141은 마지막 DRY & FINISH 섹션 높이가 504/528px이며 EPILOGUE의 상대 y가 2614/2638px이다. 텍스트는 동일하나 24px 세로 배치 차이가 있어 PHASE05 전 선택 질문으로 남긴다. 현재 PHASE03을 차단하지 않는다.
